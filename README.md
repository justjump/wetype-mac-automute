# wetype-mac-automute 🎧

> **macOS 微信键盘 (WeType) 语音输入自动淡入淡出静音守护器**  
> 彻底解决佩戴 AirPods Pro / 蓝牙耳机时，长按微信键盘语音输入背景音乐不静音的问题。

---

## 痛点与背景

在使用 macOS 版微信键盘（WeType）语音输入时：
- **外放扬声器时**：微信键盘会自动静音扬声器，防止背景声音被麦克风录入；
- **佩戴蓝牙耳机（如 AirPods Pro）时**：微信键盘 3.x 内部的 `VoiceOutputMuter` 检测到蓝牙设备的 CoreAudio 驱动返回 `mute_unsupported`，会直接放弃静音（`decision=skip`），导致戴耳机听歌/看视频时长按语音键，音乐依然原声播放，用户必须一边顶着耳机里的音乐一边说话，体验极差。

本项目通过轻量级系统守护进程，在 macOS 底层 CoreAudio 级别监听麦克风调用状态，**实现完全零侵入、全自动的背景音淡入淡出**。

---

## 核心特性

- 🎵 **丝滑淡入淡出 (Audio Ducking)**：
  - **按下语音键说话**：音乐在 ~80ms 内非线性平滑淡出至静音，无断崖硬切感；
  - **松开按键结束输入**：音乐在 ~150ms 内柔和淡入恢复至原设定音量。
- ⚡️ **极致性能**：纯原生 Objective-C + CoreAudio 编写，无任何重量级依赖，常驻 CPU 占用率低于 0.05%，内存占用仅几 MB。
- 🛡️ **零侵入与零按键冲突**：
  - **不依赖也不绑定任何按键**：完全不拦截、不注入任何键盘事件流（无需配置或安装任何改键软件）；
  - **键盘映射 100% 兼容**：无论用户是否使用了 Karabiner-Elements、系统修饰键映射，或是直接使用 Mac 自带键盘、外接机械键盘；
  - **触发方式自由**：无论在微信键盘设置里把语音键设为 `右 Option`、`双击 Cmd`、`Fn / 地球仪键` 还是鼠标侧键，只要触发了微信语音录音，服务就会纯基于音频层自动响应。
- 🚀 **开箱即用**：自带 `launchd` 自启服务配置，开机后台静默常驻。

## 安装与使用

### 一键编译与安装

```bash
git clone https://github.com/justjump/wetype-mac-automute.git
cd wetype-mac-automute
make install
```

执行完成后，程序会自动编译为原生二进制文件并注册为当前用户的后台守护服务（开机自启）。

### 卸载服务

```bash
make uninstall
```

## 技术实现原理

微信键盘在触发语音转文字时，会向系统请求麦克风录音流。本工具利用 CoreAudio 的 `kAudioDevicePropertyDeviceIsRunningSomewhere` 属性轮询监听系统所有输入设备的物理录音状态：
1. 检测到录音设备进入 Active 状态时，记录当前音量，并执行分级音量衰减序列；
2. 检测到录音设备释放时，平滑阶梯恢复至记录的目标音量。
